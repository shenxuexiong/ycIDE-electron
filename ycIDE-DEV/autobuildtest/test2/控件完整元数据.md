# ycIDE 控件元数据（编号字典版）

> `生成控件元数据.mjs` 自动导出，勿手工改（控件清单 = 脚本顶部 `CONTROLS`）。
> **读法**：属性/方法/事件各自编号，每条只在字典里定义一次；§1 控件索引里只写编号。
> 想知道某控件有什么 → 看 §1 拿编号 → 去 §2/§3/§4 按编号查定义。

## 约定

- 名称逐字一致（全半角、中英文都区分）；写错 → 编译报错，或事件不触发。
- **属性**：写在 `.efw` 控件 `properties{}` 里；编号后带 `·读写`/`·读`/`·写` 的，还能在 `.eyc` 里用 `控件名.属性名` 访问。
- **方法**：`.eyc` 里写 `控件名.方法(参数…)`；**参数按位置传递，顺序不能换**。`(可省)` 可省略、`(可重复)` 末尾可续接。
- **事件**：`.eyc` 里写子程序 `_控件名_事件名`（**窗口是 `__窗口名_事件名`**，双下划线）。
- **§1 编号读法**：`A31-A39` = A31 到 A39 全部（闭区间）；`,` 分隔不相邻的编号；`—` = 该控件没有这一类专有项（**不是「不能用」**，通用成员属性和 `M1`–`M23` 仍然可用）。
- `★` 标在**该控件的默认事件**编号后（默认事件 = 事件列表第一个，也就是 IDE 里新建事件时默认选中的那个）。
- **任何控件都能用的成员**（§1 里不再重复列；在 `.eyc` 里写 `控件名.成员名` 读写，不是 `properties{}` 项）：`标题`/`内容`/`文本`/`标记`（文本型·读写）、`可视`/`禁止`（逻辑型·读写）、`左边`/`顶边`/`宽度`/`高度`（整数型·读写）；方法 `M1`–`M23`。
- `""` = 空文本，`—` = 无 / 不适用；`本控件` = 该条所属的那个控件。
