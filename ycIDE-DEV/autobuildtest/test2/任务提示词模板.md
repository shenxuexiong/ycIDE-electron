## 3. 唯一允许的「查证」方式：写一版 → 编译

**语法/API 不确定时，让编译器告诉你，而不是读源码。**

```bash
node W:/OpenClaw/ycIDE-electron/ycIDE-DEV/out/main/cli.js build "<项目目录>" --run
```

- 错误**已回映射到易语言行号** + 中文人话解释，直接定位
- **纯语法错误约 200 毫秒就返回**（成功编译首次约 17~18 秒，命中缓存后不到 1 秒）—— 试错成本极低
- 文档没覆盖的空白（如某条类型推导规则），一律用「最小猜测 + 编译」解决
- GUI 程序 `--run` 退出码 **124 是正常的**（窗口不关→超时），不是失败
- **DLL 项目**：`--run` 会被自动跳过并打印说明（不是错误），要验证得另写宿主程序
- GUI 唯一自动化观测手段 = 代码里埋 `调试输出`（CLI 能捕获，输出带 `* ` 前缀）
